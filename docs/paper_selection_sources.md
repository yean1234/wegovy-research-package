# 논문 선별 절차와 근거 (2026-11-24)

대상은 `scripts/collect_papers_v2.py`다. 처음 만든 판(같은 날 오전)에는 선행연구를 확인하지 않고 정한 규칙이 네 개 있었다. 이 문서는 그 네 개를 선행연구에 비추어 어떻게 고쳤는지 적는다. 근거마다 확인 수준을 적었다.

## 2. 네 가지 규칙을 어떻게 고쳤나

### 규칙 1. 부작용 단어가 제목이나 결과 부분에 없으면 제외

- **문제:** 제목·초록 단계에서는 넉넉하게 포함하라는 기준(Handbook 4.6.3)과 어긋난다. 컴퓨터가 내용을 보고 탈락시키는 것이기도 하다(O'Mara-Eves 외 2015, Handbook 4.6.6.2).
- **고친 것:** 제외하지 않는다. 같은 검사를 `auto_outcome_reported`라는 예측값으로만 남긴다. "결과로 측정했는가"는 사람이 판정 기준 ②로 정한다.

### 규칙 2. 세마글루타이드가 제목에 없고 초록에 2번 미만이면 제외

- **문제:** 규칙 1과 같다. "2번"이라는 기준에도 근거가 없다.
- **고친 것:** 제외하지 않는다. `auto_semaglutide_focus`라는 예측값으로만 남긴다. "세마글루타이드만의 결과가 있는가"는 사람이 판정 기준 ③으로 정한다.
- 두 예측값이 모두 참이면 우선순위 `high`, 아니면 `low`다. 우선순위는 표집의 층으로만 쓴다(규칙 4). 이것이 O'Mara-Eves 외(2015)가 안전하다고 본 쓰임(순서·우선순위)이다.
- **검증:** 사람이 `low` 층도 판정하므로, `low` 가운데 실제로 적격이었던 비율을 낼 수 있다. 자동으로 잘랐다면 잃었을 비율이다(`summarize_paper_screening.py`).

### 규칙 3. 구획이 없는 초록은 첫 문장을 배경으로 간주

- **문제:** 문장의 역할을 위치로 정할 근거가 없다. 선행연구는 학습한 모델로 분류한다(Dernoncourt & Lee 2017). README 5장의 "비구조화 초록의 섹션은 자동 추정으로 확정하지 않는다"와도 어긋났다.
- **고친 것:** 위치로 추정하지 않는다. 구획이 없는 초록은 검증 사이트에서 문장에 번호를 붙여 보여 주고, 사람이 "몇 번째 문장까지가 배경·목적인가"(판정 기준 ④)를 고른다. 분석에서는 그 문장들만 뺀다.
- 사람의 표시가 아직 없는 초록은 문장을 모두 남기고, 남긴 문장 수를 결과에 적는다(`analyze_rq.py`의 `unstructured_abstract_sentences`).
- 구획이 있는 초록은 저자가 붙인 라벨로 Background·Objective를 뺀다(기존과 같음).

### 규칙 4. 묶음당 25편 상한과 무작위 추출

- **문제:** 체계적 문헌고찰은 검색된 기록을 모두 선별한다. 표집은 그 표준이 아니다. 25라는 숫자도 선행연구에서 온 것이 아니다.
- **고친 것:**
  - 선별 대상이 25건 이하인 묶음은 전부 사람이 본다(위마비 18건).
  - 25건을 넘는 묶음은 층화 무작위 추출을 한다. `high` 층에서 20건, `low` 층에서 5건이다. 모든 기록이 뽑힐 확률을 가지므로 컴퓨터가 탈락시키는 기록은 없다. 층별 추출 비율은 `paper_flow_v2.json`에 적는다.
  - 1차 분석의 주 분석 논문 11편은 `high` 층 안에서 반드시 포함하는 층으로 두고 표시한다(`retained_from_first_analysis`). 이 11편을 빼고도 분석할 수 있다.
- **남은 한계:** 상한 25와 층별 20/5는 팀의 작업량에 맞춘 값이다. 근거에 가장 맞는 방법은 전체 219건을 모두 선별하는 것이다. `collect_papers_v2.py`의 `CAP`을 선별 대상 수보다 크게 잡으면 전수가 된다.

### 함께 고친 것

- **위마비 검색어:** "gastric emptying"을 검색어에서 뺐다. 위 배출 지연은 위마비의 동의어가 아니라는 팀 기준(README 2장)에 맞춘 것이다. 앞 판은 넣어서 검색한 뒤 규칙 1로 뺐다.
- **Letter:** 자동 제외 목록에서 뺐다. 연구 서신(research letter)은 원자료를 보고한다.
- **제목에 "review"가 있으면 제외하던 규칙:** 삭제했다. 색인된 출판 유형(NLM publication type)으로만 판단한다.

## 4. 근거 없이 남은 것

- 우선순위를 정하는 두 검사의 세부 기준(제목 또는 배경 외 구획, 2번 이상). 이제 탈락에는 쓰지 않고, 사람 판정으로 얼마나 맞았는지 보고한다.
- 상한 25와 층별 배분 20/5.
- 서술형 리뷰·사설·논평을 출판 유형으로 빼는 것. 이 판단의 근거는 따로 확인하지 않았고, 색인이 틀린 논문은 잘못 빠질 수 있다. 빠진 61건의 목록은 `paper_screening_v2.json`에 남아 있다.
- 검색 데이터베이스가 Europe PMC(MEDLINE 기록) 하나다.
