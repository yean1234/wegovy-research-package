# 위고비 검색어 정규화 및 조사 묶음 파일럿

수집일: 2026-10-12. 이 자료는 최종 분석 코퍼스가 아니라, 조사할 묶음을 고르기 위한 검색·본문 추출·자동 선별 결과다.

## 1. 위고비의 다른 이름 처리

| 표현 | 관계 | 처리 |
|---|---|---|
| Wegovy, 위고비, 상표기호·대소문자 변형 | 같은 브랜드 표기 | WEGOVY 라벨로 정규화 |
| semaglutide, 세마글루타이드, 세마글루티드 | 유효성분 | SEMAGLUTIDE로 별도 저장. 논문 검색에 사용 |
| Ozempic, 오젬픽 / Rybelsus, 리벨서스·라이벨서스 | 같은 성분의 다른 브랜드 | 위고비로 바꾸지 않음. 적응증·용량·제형 확인 |
| GLP-1 receptor agonist, GLP-1 RA | 약물군 | 관련 검색 확장어. 위고비의 동의어가 아님 |
| GLP-1 | 호르몬 자체 또는 약물군 줄임말 | 문맥 확인 전 약물군 확정 금지 |
| tirzepatide, Mounjaro, Zepbound / liraglutide, Saxenda | 다른 성분·브랜드 | 위고비 동의어에서 제외 |

브랜드·성분 관계 근거: [EMA](https://www.ema.europa.eu/en/news/prac-concludes-eye-condition-naion-very-rare-side-effect-semaglutide-medicines-ozempic-rybelsus-wegovy).

원문은 보존하고 별도 필드에 표준 라벨을 붙인다. 위고비 기사 검색은 브랜드 이름을 중심으로, 논문 검색은 성분 이름을 중심으로 확장한다. 같은 성분이라는 사실만으로 모든 결과를 위고비 비만 치료에 일반화하지 않는다. 사전은 검색·후보 탐지 도구이며 모든 변형을 포괄하는 검증된 의학 용어집은 아니다.

## 2. 부작용 검색어와 동의어의 구분

| 묶음 | 표준 용어·표기 | 함께 검색하되 자동으로 합치지 않을 표현 |
|---|---|---|
| NAION | nonarteritic anterior ischemic optic neuropathy, 비동맥염성 전방 허혈성 시신경병증 | 실명·시력 상실은 증상 표현. NAION 확인 필요 |
| 위마비 | gastroparesis, 위마비, 위무력증 | 위 배출 지연은 기전·측정치일 수 있음. 구토와 별개 |
| 장폐색·장마비 | bowel obstruction, intestinal obstruction / ileus | 기계적 폐색과 기능적 장마비를 하위유형으로 분리. 변비는 동의어 아님 |
| 췌장염 | pancreatitis, acute pancreatitis | 췌장암·효소 수치 상승은 다른 결과 |
| 자살사고 관련 안전성 | suicidal ideation, suicidal thoughts | 자살행동·자해는 하위유형, 우울증은 별도 결과 |
| 갑상선암 | thyroid cancer, 갑상샘암 | 수질암·유두암과 동물·사람을 구분. 양성 결절과 합치지 않음 |
| 담석·담낭질환 | cholelithiasis / cholecystitis | 담석과 담낭염은 다른 질환. 절제술은 동의어 아님 |
| 흔한 위장관 증상 | nausea / vomiting / diarrhea / constipation | 각 증상을 따로 기록. 위마비·장폐색으로 자동 분류 금지 |

‘위험 증가 없음’, ‘연관성 미확인’, ‘가능성’도 보존한다. 주제 라벨은 그 문서가 해당 문제를 다룬다는 뜻이지, 약물이 그 부작용을 일으켰다는 판정이 아니다. FDA는 2026-01-13 검토에서 자살사고·행동의 위험 증가를 확인하지 못했다며 관련 경고 삭제를 요청했다. 따라서 이 묶음은 확정 부작용 대신 안전성 논쟁·보도 주제로 명명한다. [FDA 원문](https://www.fda.gov/drugs/drug-safety-communications/fda-requests-removal-suicidal-behavior-and-ideation-warning-glucagon-peptide-1-receptor-agonist-glp)

## 3. 노션 방식 적용과 실제 수집 결과

기준 문서: [학부 팀플 계획 v2](https://app.notion.com/p/3f4ed99f9ad58155b677c8806780e7a4).

논문과 기사를 부작용 묶음별로 수집하고 개별 기사–논문을 강제로 1:1 연결하지 않았다. 논문은 Europe PMC, 기사는 네이버 공개 뉴스 검색으로 URL을 확보한 뒤 언론사 본문을 추출했다. 네이버 API 키를 사용한 수집은 수행하지 않았다. 공개 검색 결과의 순위·페이지 구성이 API 결과와 같다고 가정할 수 없다.

검색 기간은 2021-01-01부터 2026-10-12까지로 지정했다. 최초 24개 검색식 각각 두 시작 위치를 조회하고, 최근 보도 쏠림을 완화하기 위해 7개 묶음의 2023–2024년 및 2025년 구간을 추가 조회했다. 일부 페이지는 동일 결과를 반환했다. 검색 결과 전체를 전수 수집한 것은 아니다. 논문 초기 검색 후 2021–2025년 제목 중심 보완 검색을 수행했다. 검색 날짜 및 색인 날짜는 논문의 온라인 최초 공개일과 구분해야 한다.

중복 URL을 통합한 후보는 345건이며, 자동 본문 추출 성공 330건, 본문 부족 12건, 접근·추출 실패 3건이다. 330건 모두가 연구 적합 기사라는 뜻은 아니다. 본문 지문 기반 유사 중복 3건을 추가 표시했다.

| 묶음 | 해당 검색식으로 확보한 고유 URL | 전체 수집분 중 자동 선별 후보 |
|---|---:|---:|
| 비동맥염성 앞허혈시신경병증 | 67 | 42 |
| 위마비 | 40 | 21 |
| 장폐색·장마비 | 55 | 33 |
| 췌장염 | 67 | 59 |
| 자살사고·자살행동 관련 안전성 | 64 | 32 |
| 갑상선암 | 44 | 16 |
| 담석·담낭질환 | 46 | 37 |
| 흔한 위장관 증상(확장 후보) | 29 | 59 |

자동 선별 조건: 본문 700자 이상, 위고비 언급, 전용 본문 영역 추출, 기간 내 날짜 파싱 성공, 질환 언급 주변 450자에 논문·연구 결과 등의 표현 존재, 유사 중복 제외. 날짜는 메타데이터·본문에서 추출한 값으로 사람이 검증했다는 의미가 아니다. 한 기사가 여러 묶음에 포함될 수 있어 행을 합하면 전체 기사 수가 되지 않는다. 다른 묶음 검색에서 발견한 문서도 검사했기 때문에 두 번째 수가 첫 번째보다 클 수 있다.

이 조건은 연구 관련성을 완전히 판정하지 못한다. 비교약물만 다룬 연구, 일반 부작용 나열, 광고, 다른 연구가 가까이에 언급된 기사 등을 추가 확인해야 한다. 언론사명은 아직 일괄 검증하지 않아 source_domain과 outlet_verified를 구분했다. 기사 제목·본문 차원의 전재·재서술 중복도 남아 있을 수 있다.

## 4. 묶음 선정

| 우선순위 | 묶음 | 선정 판단 |
|---|---|---|
| 우선 | NAION | 논문 후보 3편, 자동 기사 후보 42건. 실명이라는 제목 표현과 구체적 진단·집단 범위를 비교하기 좋음 |
| 우선 | 자살사고 관련 안전성 | 논문 후보 3편, 자동 기사 후보 32건. 관찰연구·자발보고·시험 사후분석의 서로 다른 근거와 위험 증가 부정 보도까지 포함 가능 |
| 조건부 추가 | 위마비 | 성분이 확인되는 논문 후보 2편, 자동 기사 후보 21건. 단순 위 배출 지연과 증례·코호트 구분 필요. 탈락 후 20건 미만일 수 있음 |
| 조건부 추가 | 췌장염 | 논문 후보 3편, 자동 기사 후보 59건. 일반 경고 나열을 제외하고 신규 발생·재발·증례를 구분해야 함 |
| 예비 | 장폐색·장마비 | 성분 관련 증례 2편과 계열 고찰. 자동 기사 후보 33건이나 증례 중심이고 위마비와 중복 보도가 많음 |
| 예비 | 갑상선암 | 성분 관련 고찰 2편. 자동 기사 후보 16건으로 목표 20–40건에 미달 |
| 예비 | 담석·담낭질환 | 자동 기사 후보 37건. 성분별 논문·기사 내용 확인이 필요하고 계열 전체 결과가 섞임 |
| 확장 | 흔한 위장관 증상 | 성분 관련 논문 후보 2편, 자동 기사 후보 59건. 범위가 넓어 증상별로 좁혀야 전달 표현 비교가 해석 가능 |

우선 4개 묶음(NAION·자살사고·위마비·췌장염)의 자동 후보를 합친 고유 기사는 110건이다. 이는 노션의 최종 100–150건 목표를 달성했다는 뜻이 아니다. 내용 검토 후 줄어들며, 전체 8개 묶음의 자동 후보 합집합도 133건이다. 따라서 현재 결론은 ‘조사할 후보 묶음 선정’까지이며, 4개 묶음 모두 충분한 최종 표본을 확보했다고 확정할 수 없다. 본 수집에서는 같은 포함 기준으로 검색을 확장하고 검토 후 묶음별 20–40건 및 전체 고유 100–150건을 확인해야 한다. 부족한 묶음을 수량만 맞추려고 서로 다른 질환으로 합치지 않는다.

논문 원문 초록은 수집 과정에서 확인했으나 이 배포 파일에는 제목·DOI·출처·작성한 범위 메모를 제공한다. 본 분석에서는 원문 초록과 번역을 별도 저장하고, Background·Importance·Objectives 등의 배경 섹션은 제외한 Methods·Results·Conclusions 중심 분석 텍스트를 만들어야 한다. 비구조화 초록의 섹션은 자동 추정으로 확정하지 않는다.

## 6. RQ3 순환 논리와 라벨

수집할 때 라벨을 저장해도 된다. K-means는 데이터 표의 모든 열을 자동으로 참고하는 것이 아니라, 코드가 전달한 수치 행렬만 사용한다. 기사유형·부작용·단정 비율·조건 유무를 별도 메타데이터로 저장하되 군집 입력 X에는 넣지 않는다. 원문 텍스트로 만든 TF-IDF 또는 주제 분포를 입력하고 군집을 만든 뒤 메타데이터로 비교한다.

‘논문/기사/기사제목’은 서로 독립적인 세 종류의 문서라기보다 논문 초록과 기사 본문·제목의 관계로 관리하는 편이 낫다. 제목과 본문은 같은 article_id에 연결한다. 단정 비율로 먼저 나눈 군집의 단정 비율 차이는 새로운 결과가 아니다. 내용 군집이 특정 부작용에 몰리면 전달 유형이라고 단정하지 않고 주제 중심 군집일 가능성을 함께 보고한다. 한 기사의 다중 부작용 라벨 때문에 RQ1·RQ3 입력에 문서를 복제하지 않는다.

## 7. 파일과 재사용

- normalization.json: 브랜드·성분·관련 약물군, 질환별 동의어·확장어 사전.
- article_candidates.json: 345개 URL의 제목·수집일·날짜·추출 상태·잠정 라벨. final_side_effect_labels는 미확정으로 남김.
- paper_candidates.json: 논문 후보 23편의 식별자와 범위 메모. 배경 자료 포함.
- pilot_counts.json / collection_summary.json: 중복을 구분한 집계.
- search_audit.json: 실제 실행한 뉴스 검색 URL과 반환 URL.
- scripts/: 실행한 수집·정규화·선별 스크립트. Python과 lxml 필요.

공개 검색 및 언론사 HTML은 바뀔 수 있어 재실행 결과가 같다고 보장되지 않는다. scripts에서 collect_papers.py, target_papers.py, collect_news.py, scrape_news.py, extend_historical.py, analyze_pilot.py 순으로 실행한다. 현재 스크립트 날짜는 파일럿 기간으로 고정되어 있다. 검색 감사 파일은 최초 수집 당시 쿼리의 근거다. 네트워크 재실행에는 원문 제공처의 접근 조건이 적용된다. 현재 검색 코드는 API 키를 읽거나 사용하지 않는다.

기사 전문·논문 초록 전문은 재배포 패키지에 포함하지 않았다. 최종 분석용 본문·번역·정제 결과가 준비됐다고 해석하면 안 된다.

## 8. API 키를 공개하지 않고 사용하기

키나 Client Secret을 채팅·노션·공개 저장소에 붙이지 않는다. 사용자 PC의 환경변수 또는 접근을 제한한 .env에 저장하고 코드는 환경변수를 읽도록 구성한다. .env는 암호화 보관함이 아니므로 파일 공유도 피한다. .gitignore에 등록해도 이미 커밋한 비밀이 삭제되는 것은 아니다. 예시 파일의 YOUR_... 값은 자리표시자이며 실제 키가 없다. 이미 외부에 공개된 키는 발급 서비스에서 폐기·교체한다.

네이버는 Client Secret을 외부에 노출하지 않도록 안내한다. [네이버 공식 FAQ](https://developers.naver.com/products/intro/faq/faq.md). 발급 서비스가 확인되면 그 서비스의 설정 방식에 맞춰 연결한다. 이 패키지의 공개 검색 파일럿에는 키가 필요하지 않았다.
